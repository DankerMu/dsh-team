## MODIFIED Requirements

### Requirement: 平台登录页面

平台 MUST 提供可提交的中文登录表单，以同源JSON请求调用既有登录接口；加载期间 MUST 明确显示状态并阻止重复提交。邮箱不存在与密码错误 MUST 使用同一中文提示；限流和已禁用账号 MUST 分别显示相应中文提示。登录成功后 MUST 按返回的角色导航：员工或无法识别角色时导航到固定同源根路径，由既有网关处理实例状态；管理员读取一次既有模型配置接口，配置不完整（地址为空、密钥未设置、模型清单为空或默认模型为空）时导航到 `/_platform/admin/models`，其余情况（配置完整、读取失败或回应异常）导航到 `/_platform/admin`，读取失败 MUST NOT 把已成功的登录显示为失败。失败 MUST 留在登录页并允许恢复操作。密码 MUST NOT 进入URL、持久浏览器存储或诊断输出。

#### Scenario: 正确凭据从浏览器进入已认证入口

- **WHEN** 员工在实际编译的登录页面提交可用账号的正确凭据
- **THEN** 平台建立真实平台会话，浏览器导航到根路径；实例的转发或等待行为仍由既有网关负责

#### Scenario: 管理员在模型未配置时直达模型配置页

- **WHEN** 管理员在模型配置不完整的平台上通过实际编译的登录页面登录
- **THEN** 浏览器导航到 `/_platform/admin/models`，不经过根路径或等待页，也不启动该管理员的实例

#### Scenario: 管理员在模型已配置或读取失败时进入后台首页

- **WHEN** 管理员登录时模型配置完整，或模型配置读取返回非200、网络失败或格式异常
- **THEN** 浏览器导航到 `/_platform/admin`，登录不显示失败提示

#### Scenario: 登录错误和加载状态可见

- **WHEN** 登录请求尚未完成，或真实接口返回凭据错误、限流、账号禁用
- **THEN** 未完成期间显示加载且不重复发送请求；对应错误显示中文提示且不导航，不暴露原始服务端消息或密码，随后可再次操作

## ADDED Requirements

### Requirement: 登录与注册页采用左右分栏布局

登录和注册页面 MUST 在宽屏下并排显示品牌区（产品名与一句事实性说明）和表单区，在窄屏下纵向堆叠且无横向滚动；表单 MUST 保留既有可访问名称、状态区域以及到注册页和账号设置页的入口。平台各页面 MUST 共用一套样式变量（颜色、圆角、焦点框、主按钮、错误提示），不改变其他页面的结构，不引入外部字体或资源。

#### Scenario: 宽屏和窄屏的登录页

- **WHEN** 真实浏览器分别以 1280×800 和 390×844 打开实际编译的登录页和注册页
- **THEN** 宽屏显示并排的品牌区和表单区，窄屏纵向堆叠且页面宽度不超过视口；表单可按原可访问名称定位，控制台无错误，截图留存
