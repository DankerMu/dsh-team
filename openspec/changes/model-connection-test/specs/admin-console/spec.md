## MODIFIED Requirements

### Requirement: 模型配置页

后台 MUST 提供模型地址、密钥、模型清单、默认模型的编辑页，并提供“重启全部运行中的实例”的操作。

#### Scenario: 保存后提示生效方式

- **WHEN** 管理员保存模型配置
- **THEN** 界面提示“下次启动实例时生效”，并提供立即重启全部运行中实例的按钮

#### Scenario: 密钥输入与保存结果

- **WHEN** 管理员填写模型地址、密钥、模型清单、可选上下文窗口及默认模型并保存
- **THEN** 合法配置保存且再次打开可读回非秘密字段；密钥输入被清空并只显示“已设置”状态，浏览器收到的回应没有密钥原文
- **AND** 留空密钥输入保留已存密钥；非法默认模型或上下文窗口显示校验提示，不得虚报保存成功

#### Scenario: 明确确认后重启

- **WHEN** 管理员保存后选择重启全部运行中的实例
- **THEN** 界面明确确认后才请求既有重启接口，取消不发请求；提交期间阻止重复或交叉变更
- **AND** 回应只代表启动准入时不得声称全部已就绪，失败须提示可能已有部分实例被处理

#### Scenario: 地址填写说明

- **WHEN** 管理员编辑模型地址
- **THEN** 输入框旁显示“OpenAI 兼容地址，通常以 /v1 结尾”的说明；平台不自动补全或改写地址

## ADDED Requirements

### Requirement: 模型连接测试

后台 MUST 提供对已保存模型配置的连接测试：仅管理员可用，只用已保存的地址、密钥和默认模型，按与 DSH 相同的规则（地址以 `/` 结尾时追加 `chat/completions`，否则追加 `/chat/completions`）发一个最小的非流式补全请求，并用封闭集结果说明成败。模型配置的读取和保存接口本身仍不发起模型连接。

#### Scenario: 已保存配置连通

- **WHEN** 管理员保存完整模型配置后点击“测试连接”，上游返回带 `choices` 数组的 JSON 200
- **THEN** 平台恰好发出一次请求：路径与 DSH 一致，带 `Authorization: Bearer <已存密钥>`，请求体为默认模型、单条用户消息、`max_tokens: 1`、`stream: false`；接口返回 `result: ok` 和耗时，页面显示连接成功

#### Scenario: 失败分类

- **WHEN** 上游返回 401/403、404、其他 4xx 或 5xx
- **THEN** 接口返回 200，`result` 依次为 `unauthorized`、`not-found`、`rejected`、`server-error`，并带 `httpStatus`
- **AND** 3xx、非 JSON 或缺少 `choices` 数组的 2xx、或超过 64KiB 的回应体，`result` 为 `bad-response`
- **AND** 请求超过 20 秒，`result` 为 `timeout`；DNS、连接、TLS 失败或传输中断，`result` 为 `unreachable`；未收到状态码时 `httpStatus` 为 null
- **AND** 回应、日志和审计都不包含密钥、上游回应体或完整 URL；不跟随重定向；回应体最多读取 64KiB
- **AND** 页面对每种结果显示固定中文说明，`not-found` 和 `bad-response` 额外提示“OpenAI 兼容地址通常以 /v1 结尾”

#### Scenario: 配置不完整或无效

- **WHEN** 已保存的模型配置缺少地址、密钥、模型清单或默认模型时请求测试
- **THEN** 接口返回 `result: unconfigured`，不发出任何外部请求；判断与实例启动使用同一完整性规则
- **AND** 已保存的地址无法解析或不是 http/https 时返回 `invalid-address`；密钥不能作为请求头发送时返回 `invalid-key`；两者都不发出外部请求

#### Scenario: 取消与关闭

- **WHEN** 测试进行中，客户端断开连接，或者平台开始关闭
- **THEN** 平台立即中止对上游的请求，关闭不等待 20 秒期限；多个管理员同时测试时互不串行

#### Scenario: 授权与请求形状

- **WHEN** 请求没有当前有效会话、来自员工或已降权的管理员、请求体不是空 JSON 对象，或者来源不是平台同源
- **THEN** 分别按既有后台变更策略返回 401、403、400/415 或拒绝来源，不发出外部请求；读完请求体后重新校验管理员会话
- **AND** 页面上 401 回到登录页，403 进入无权限状态；测试与保存、重启共用同一个待处理防重入，等待期间显示“正在测试连接…”，测试不修改任何表单输入
