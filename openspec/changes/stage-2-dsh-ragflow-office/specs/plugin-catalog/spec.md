## Purpose

预装插件目录与部署形态配置：管理员在后台为每个预装插件和 bundle 选择员工自选、强制开或强制关，配置插件安装源、仓库探测和联网工具；员工插件页为每个预装项提供开关，DSH 自带的安装、更新、卸载入口保留。

## ADDED Requirements

### Requirement: 预装目录有唯一来源

预装插件和 bundle 的清单 MUST 只有一份来源，同时决定用户镜像预装的内容和后台列出的条目。每个条目 MUST 有稳定的标识、包名、中文名和镜像默认启用状态。镜像预装内容与清单不一致时，用户镜像构建 MUST 失败。

#### Scenario: 后台列表与镜像一致

- **WHEN** 管理员打开插件目录页
- **THEN** 列出的条目与用户镜像实际预装的插件和 bundle 完全一致，名称为中文

#### Scenario: 清单与镜像不一致时构建失败

- **WHEN** 清单中有一个条目，镜像构建没有预装它
- **THEN** 用户镜像构建失败并指出不一致的条目

### Requirement: 预装项三种管理状态

每个预装项 MUST 处于且只处于一种管理状态：员工自选、强制开、强制关，初始为员工自选。员工自选时，员工插件页的开关可用，默认值来自镜像。强制开或强制关时，该项在员工实例中 MUST 处于对应的启用状态，员工插件页显示为锁定且员工不能更改。状态变更 MUST 在该员工实例下次启动时生效。

#### Scenario: 强制关的项员工打不开

- **WHEN** 管理员把「知识库」设为强制关，员工的实例之后重新启动
- **THEN** 员工插件页中「知识库」显示为关闭且锁定，员工无法打开

#### Scenario: 强制开的项员工关不掉

- **WHEN** 管理员把「公文与材料写作」所在的 bundle 设为强制开，员工实例重新启动
- **THEN** 该 bundle 显示为开启且锁定，员工无法关闭

#### Scenario: 员工自选的项可以切换

- **WHEN** 某项为员工自选，员工在插件页关闭它
- **THEN** 该项被关闭，管理员的设置不变，其他员工不受影响

#### Scenario: 运行中的实例不立即变化

- **WHEN** 管理员修改某项状态时员工实例正在运行
- **THEN** 该实例在停止前保持原状态，下次启动后才按新状态生效

### Requirement: 员工插件页每个预装项都有开关

员工插件页 MUST 为每个预装插件和 bundle 显示一张带开关的卡片，包括办公 Agent bundle。卡片 MUST 标明当前状态，强制的项标明「由管理员设定」。

#### Scenario: 全部预装项可见

- **WHEN** 新员工首次打开插件页
- **THEN** 清单中的每个预装项都有一张卡片，并显示开关状态

### Requirement: 安装入口保留并使用管理员配置的安装源

DSH 自带的添加插件、更新、卸载入口 MUST 保留，员工和 Agent 可以安装其他插件。插件安装使用的 npm 源列表和是否开启仓库探测 MUST 由管理员在后台配置，经覆盖层下发，员工不能修改；变更在实例下次启动时生效。仓库探测关闭时，实例 MUST NOT 主动访问公共插件仓库。

#### Scenario: 联网部署可以安装插件

- **WHEN** 管理员保留默认公共源，员工在插件页添加一个公共插件
- **THEN** 插件安装成功并出现在员工插件页

#### Scenario: 内网部署关闭仓库探测

- **WHEN** 管理员关闭仓库探测并把安装源指向内网镜像，员工实例重启
- **THEN** 实例不访问公共插件仓库，安装请求只发往内网镜像

#### Scenario: 员工不能改安装源

- **WHEN** 员工在 DSH 设置中查看插件安装源
- **THEN** 该设置显示为受管锁定，值为管理员配置的源列表

### Requirement: 联网工具由管理员开关

联网搜索和抓取工具 MUST 默认对所有 Agent 关闭。管理员可以在后台打开；打开后在实例下次启动时对所有 Agent 生效，关闭同理。

#### Scenario: 默认没有联网工具

- **WHEN** 管理员没有修改过联网工具开关，员工新建 Session
- **THEN** 任何 Agent 的可用工具中都没有联网搜索和抓取

#### Scenario: 打开后下次启动可用

- **WHEN** 管理员打开联网工具，员工实例重新启动
- **THEN** Agent 的可用工具中出现联网搜索和抓取
