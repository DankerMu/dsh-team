## ADDED Requirements

### Requirement: 后台采用侧栏导航与玻璃面板布局

后台各页面 MUST 在宽屏下以左侧玻璃侧栏承载既有后台导航、右侧玻璃面板承载页面内容，在窄屏下导航变为顶部横向栏且只在导航自身内滚动；表格、对话框、表单和实例状态 MUST 使用平台统一的玻璃视觉，实例状态以状态标签显示且文字不变；导航可访问名称、当前页标记和各页面既有行为 MUST 保持不变。

#### Scenario: 后台页面在宽屏和窄屏下的布局

- **WHEN** 管理员在真实浏览器以 1280×800 和 390×844 打开账号、实例、审计、模型和运行参数页面
- **THEN** 宽屏为侧栏加内容面板，窄屏为顶部导航加内容且页面无横向滚动；导航仍按“后台导航”定位并标记当前页，控制台无错误，截图留存
