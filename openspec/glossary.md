# Glossary

本项目是一个单机 Docker 部署的企业多用户办公平台：平台管理账号和实例，每个用户使用自己的 DSH。

## Language

**平台**:
本仓库的管理层服务（账号、编排、网关、后台），不含 DSH 本身。
_Avoid_: 系统, 管理层, hub, 后端

**实例**:
某个用户专属的 DSH 容器加它的数据卷，一个用户恰好一个。
_Avoid_: 容器, 环境, 工作台, sandbox

**受管覆盖层**:
平台为每个实例生成、只读挂载、用户改不了的 DSH 配置文件。
_Avoid_: 托管配置, managed patch, 配置覆盖

**网关**:
平台里把已登录用户的请求转发到其实例的部分。
_Avoid_: 代理, 反向代理, router

**平台会话**:
用户在平台的登录状态。
_Avoid_: Session, 登录态, 会话

**Session**:
DSH 里的一次对话；专指 DSH 的概念，不用来指平台登录状态。
_Avoid_: 会话, 对话, 聊天

**知识库**:
RAGFlow 的一个 dataset。
_Avoid_: 数据集, 文档库, KB
